# Stochastic vs Batch Gradient Descent Comparison

A comparative benchmark analyzing optimization behavior, training speed, and convergence stability between Stochastic Gradient Descent (SGD) and Batch Gradient Descent (GD).

## Key Components

- **`Stochastic_vs_Batch_Gradient_Descent.ipynb`**: Implementation of SGD and Batch GD algorithms, tracking loss curves per iteration.
- **`Stochastic_vs_Batch_Gradient_Descent_Report.pdf`**: Detailed technical report evaluating convergence speed, noise sensitivity, and computational complexity.
