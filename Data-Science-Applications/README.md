# Data Science Applications

Exploratory data analysis (EDA) and predictive modeling applied to real-world domain datasets:

- **Air Quality Analysis (`Air_Quality_Analysis.ipynb`)**: Time-series trend analysis and multivariate regression on air contaminant sensor data from an Italian field laboratory (`Air Quality.csv`).
- **Diabetes Prediction (`Diabetes_Classification.ipynb`)**: Binary classification and feature importance evaluation on Pima Indians diagnostic health data (`diabetes.csv`).
