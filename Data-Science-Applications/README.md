# Data Science Applications

Hands-on exploratory data analysis (EDA) and predictive modeling applied to real-world domain datasets:

- **Air Quality Analysis (`Air_Quality_Analysis.ipynb`)**: Time-series trend analysis and multivariate regression on air contaminant sensor data (`Air Quality.csv`).
- **Diabetes Prediction (`Diabetes_Classification.ipynb`)**: Binary classification and feature importance evaluation on healthcare diagnostic data (`diabetes.csv`).
