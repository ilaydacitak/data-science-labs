# UrbanSound8K Audio Classification Project

An audio signal processing and machine learning classification project using the **UrbanSound8K** dataset to classify urban environmental sounds into 10 distinct categories.

## Dataset & Classes

Classifies audio clips into 10 urban sound classes:
- `0`: Air Conditioner
- `1`: Car Horn
- `2`: Children Playing
- `3`: Dog Bark
- `4`: Drilling
- `5`: Engine Idling
- `6`: Gun Shot
- `7`: Jackhammer
- `8`: Siren
- `9`: Street Music

## Methodology

- Audio feature extraction and signal preprocessing.
- Multi-class classification modeling and evaluation using accuracy, confusion matrices, and classification metrics.
