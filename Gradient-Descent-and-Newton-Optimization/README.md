# Unconstrained Quadratic Minimization: Steepest Descent vs Newton Method

Numerical optimization study implementing first-order and second-order optimization algorithms from scratch to find the global minimum of a quadratic objective function:

$$g(x, y) = x^2 + xy + 2y^2 + 5x + 3y$$

## Algorithms Implemented

- **Steepest Gradient Descent**: First-order iterative optimization using gradient vectors and step-size line search.
- **Newton-Raphson Method**: Second-order optimization utilizing Hessian matrices for rapid quadratic convergence.
- **Convergence Analysis**: Compares iteration counts, trajectory paths, and execution times to reach global minimum.
